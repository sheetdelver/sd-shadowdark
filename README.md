# SheetDelver — Shadowdark RPG

[![CI](https://github.com/sheetdelver/sd-shadowdark/actions/workflows/ci-shadowdark.yaml/badge.svg?branch=main)](https://github.com/sheetdelver/sd-shadowdark/actions/workflows/ci-shadowdark.yaml?query=branch%3Amain)

Character sheets and tools for playing Shadowdark RPG with SheetDelver.

## Character sheets

- Responsive tabbed and paper-style views.
- Edit names, base ability scores and maximum HP.
- Roll ability checks, attacks and spells; share item cards to chat.
- Track inventory, wealth, talents, effects and notes.
- Manage Pulp luck, Renown and limited-use abilities.
- Complete rests with HP recovery, spell resets and optional ration consumption.
- Track light timers, spell loss and scroll/wand use.

## Character creation

- Character Generator, step-by-step Creator and Shadowdarklings JSON import.
- Guided talent, language, spell, HP and equipment choices.
- Level-up workflow capped at level 10, following the core rules.

## GM tools

- Browse and filter native and community monster stat blocks.
- Build treasure, armor, weapons, potions, scrolls, wands, utility items and boons.
- Roll available tables, use original alternatives or enter your own results.
- Add item attributes, personalities and supported permanent effects.
- Preview items, save a reusable library and assign items to characters.

Ammunition spending, damage application and scene automation remain manual or
Foundry-managed. Descriptive item qualities do not automatically create effects.

## Requirements

**SheetDelver Core 0.22.3 or newer.** Optional native artwork packages are supported.

See the [changelog](CHANGELOG.md) for release highlights.
